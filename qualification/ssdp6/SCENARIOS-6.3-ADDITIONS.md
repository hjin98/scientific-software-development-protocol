# Protocol 6.3 Project Engineering Memory Qualification Additions

These scenarios are non-authoritative qualification specifications for Protocol 6.3. They supplement, and do not replace, accepted scenarios 1-115. Each required case must use a discriminating negative/counterfactual fixture rather than word-presence checks.
