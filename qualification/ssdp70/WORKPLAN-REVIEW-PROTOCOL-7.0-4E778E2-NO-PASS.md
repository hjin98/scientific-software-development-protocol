- **B1 — the X1 repair removes silence-as-null but reintroduces false gaps for compliant delegates.** The asks are unconditional but their content is conditional: element 2 asks for disclosure "if it evaluated more than one variant", element 1 for a null envelope "if its work inquired over realized results", and an SSDP-governed change-only delegate that finds nothing "adds nothing" under the change-only relief row carried on the same surface. This contradicts §6.3.11's gap trigger ("when a delegate returns without them") and reintroduces what the `adaac7b` X1 finding called the valid part of `41434b1` B2 ("false gaps for returns that were never owed"). The false-gap variant scores only the evidently-impossible class and only variant/null gaps, so qualification would not detect it. Related: the null ask's condition ("inquired over realized results") differs from the "owed" row (produces, runs or reviews); safety holds only because the gap rule uses "owed".
